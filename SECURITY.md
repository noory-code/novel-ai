# Security Policy

## Supported Versions

Security fixes target the latest version on the `main` branch. Older plugin versions are not
maintained after a newer version is published.

## Reporting a Vulnerability

Use GitHub's **Report a vulnerability** form in the repository Security tab. This creates a private
discussion with the maintainers. Do not open a public issue or pull request before a fix is ready.

Include:

- the affected plugin and version;
- a minimal reproduction;
- the expected and observed behavior;
- the practical impact;
- any mitigation already tested.

The maintainers will acknowledge a complete report within seven calendar days, provide a status
update at least every fourteen calendar days while it remains open, and coordinate public
disclosure after a fix or mitigation is available.

This policy covers code shipped by this repository. Reports about Claude Code, Codex, GitHub, or a
third-party dependency should also be sent to that project's security contact.
