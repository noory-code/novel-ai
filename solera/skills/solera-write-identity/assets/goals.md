# Template: Rough Directions (optional, v3)

This is a human jotting-pad. In v3 there is no "Goal" work item — Goals became Concepts on the Living axis. This file captures direction candidates that will seed your first `solera-write-concept` drawings.

## Location

```
{project_path}/workspace/identity/rough-directions.md
```

## Format

```markdown
# Rough Directions

> Last updated: {YYYY-MM-DD}
>
> Candidate directions. Not commitments. Feed these into `solera-write-concept` when you're ready to draw the Living map.

## Directions

- **{direction name}** — {one line on what this area is about; why it matters}
  - Linked value: {core value from core-values.md, if any}

- **{direction name}** — ...

## Notes

- Some of these may merge into a single Concept; others may split into several.
- Some may be rejected after more thought — that's expected.
- Nothing here is a work item. Concepts, Milestones, and Stories come later.
```

## Example

```markdown
# Rough Directions

> Last updated: 2026-04-16
>
> Candidate directions for task-app. Not commitments.

## Directions

- **Capture speed** — capturing a task must feel instant; sub-second from intent to saved.
  - Linked value: minimize friction
- **Lifecycle clarity** — a task is always in exactly one clear state; no hidden purgatory.
  - Linked value: no hidden complexity
- **Search that works** — finding any prior task in under 3 seconds by text.
  - Linked value: retrievable history

## Notes

- "Capture speed" and "Lifecycle clarity" may become two Concepts, or "Capture speed" may be a facet within "Lifecycle".
- Decide after sitting with these for a day.
```

## Quality Criteria

- [ ] Each direction is described in one line (not a paragraph — that's a Concept's job).
- [ ] Linked to core values where obvious; skipped where not.
- [ ] Noted as candidates, not commitments.
- [ ] Human-written, not AI-invented. AI may ask clarifying questions but must not add directions the human didn't name.
