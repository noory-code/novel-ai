# Template: Status (승인 대기)

사람의 승인을 기다리는 작업의 상태 문서입니다.

## 위치

```
[project]/workspace/pending/[작업명]/_status.md
```

## 템플릿

```markdown
# 승인 대기: [작업명]

## 상태
**사람 승인 대기 중**

## 준비된 작업
- [x] 초안 작성 완료

## 사람이 확인해야 할 사항
- [ ] 목표가 적절한가?
- [ ] 분해가 적절한가?

## 승인 후 다음 단계
→ [다음 작업]
```

## 품질 기준

- [ ] 상태가 명확한가?
- [ ] 사람이 확인해야 할 사항이 체크리스트로 정리되어 있는가?
- [ ] 승인 후 다음 단계가 명시되어 있는가?
