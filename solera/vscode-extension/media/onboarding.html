Solera

This workspace is not yet a Solera project.

1 — Install the Solera plugin in Claude Code

Solera is a Claude Code plugin that runs the human ↔ AI workflow (Identity, Personas, Journeys, Narratives, Concepts, Milestones, Stories, Releases). Solera is the visual layer over its data.

From Claude Code, register the marketplace and install:

/plugin install solera

2 — Run solera-init

From Claude Code, in this workspace folder: 

/solera-init

This creates .solera/ with the v4 directory layout (identity/, personas/, journeys/, narratives/, concepts/, milestones/, stories/, releases/, catalog/published/) plus progress.md.

3 — Install uv if you don't have it

Solera's local server is a Python process started by this extension via uv run python -m solera_map. Install uv from docs.astral.sh/uv/ — Solera cannot install it for you (Marketplace policy bans extensions that download executables).

4 — Re-open

Run Solera: Open from the Command Palette (Cmd+Shift+P / Ctrl+Shift+P) once .solera/ exists in this folder.

Already on Solera v3 (with a workspace/ folder at the project root)? Run /solera-migrate-workspace-to-dotsolera in Claude Code to relocate to .solera/.
